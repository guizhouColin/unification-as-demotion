# 统一即降级

> 一个思想试验：如果每一次物理学的统一，都不是旧理论被推翻，
> 而是旧理论被降格成新结构在某个极限下的近似 —— 那我们该怎样找下一个？

## 核心追问

从 E=mc² 出发，追问三件事：

1. E=mc² 究竟说了什么、没说什么
2. 百年间电弱统一、QCD、标准模型如何一层层"降级"了旧理论
3. 引力与量子场论的统一为何至今未完成，以及"完成"可能长什么样

## 「降级」的含义

不是相对主义，是严格的极限关系：

- 狭义相对论 = 广义相对论在局部惯性系的极限（v≪c 时退化为牛顿力学）
- 量子电动力学 = 标准模型在低能下的有效场论
- 广义相对论与量子场论，很可能都是某个更底层结构的有效近似

判断标准是可计算的对应极限，不是哲学修辞。

## 证据分级

报告中每条路线、每个候选理论都标注等级，读者不应把自洽当证实。

| 等级 | 含义 |
|------|------|
| E0 | 有实验/观测确认的信号 |
| E1 | 数学自洽，无已确认的独特信号 |
| E2 | 受现有观测约束，尚未排除 |
| E3 | 纯猜想，暂无可检验预言 |

## 贡献约定

提任何一个新想法，先写下：**什么结果会让我放弃它**。
写不出来，就还只是美学偏好。
